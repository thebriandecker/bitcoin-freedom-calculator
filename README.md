# Bitcoin Freedom Year Calculator

Free tool from The Wealth Society (@thebriandecker): find the first year your bitcoin could pay your yearly income by borrowing against it instead of selling it, stress-tested through modeled crashes.

Live: https://thebriandecker.github.io/bitcoin-freedom-calculator/

Source of truth lives in `Wealth Society HQ\Research\Bitcoin-Freedom-Calculator\bitcoin-freedom-year.html`; this `index.html` is generated by `build_standalone.py` there. Educational scenario planning only, not financial advice.
